# disney-three-rooms

Agent Skill for turning an idea into an ambitious, actionable, and stress-tested plan through three strictly separated thinking modes:

Dreamer → Realist → Critic → Synthesis

## Installation

Copy or link .agents/skills/disney-three-rooms into the client’s project or user-level skills directory.

## Usage

Activate the skill when the user wants to develop an idea, start or evaluate a project, or explicitly asks to use the Disney Three Rooms method.

The conversation always begins in the Dreamer room and proceeds one question at a time through the Realist and Critic rooms before producing the final Synthesis.
